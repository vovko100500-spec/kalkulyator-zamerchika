# Архитектура: Мобильный калькулятор замерщика (Telegram Mini App)

## 1. Концепция системы

Автономное клиентское веб-приложение (Single Page Application), оптимизированное для работы внутри Telegram WebApp и как самостоятельное PWA.

Главный приоритет — моментальный расчёт себестоимости и маржи прямо на объекте без обращения к серверу.

## 2. Поток данных (Data Flow)

```
[Пользовательский ввод (UI)]
        │
        ▼
[Zustand Store: draftMeasurement]
        │
        ▼
[Calculator Engine (Pure TS Functions)] ◄── [Прайс-лист из IndexedDB (Dexie)]
        │
        ▼
[Calculation Result: Спецификация + ФОТ + Маржа]
        │
        ▼
[UI Экран результатов] ──► [Сохранение в историю (IndexedDB)]
```

## 4. Стейт и хранение данных

### 4.1. Текущий замер (`useMeasurementStore`)

Сохраняется в `localStorage` при каждом изменении, чтобы избежать потери данных при случайном закрытии Telegram.

### 4.2. Каталог цен (`useCatalogStore` + Dexie)

- Позволяет пользователю прямо в приложении изменить цену за метр трубы или ставку бригады.
- Хранит дату последнего обновления цен.
